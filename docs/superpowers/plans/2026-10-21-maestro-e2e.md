# Maestro E2E High-Leverage Testing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a minimal, high-leverage Maestro E2E test suite for the Lifecore native iOS app covering core user flows and physiological engines.

**Architecture:** Add targeted `.accessibilityIdentifier` modifiers to 7 SwiftUI view components; create 4 high-leverage Maestro test flows and master suite in `.maestro/`; write an automated shell runner (`scripts/run_e2e.sh`) that automates simulator detection, building, installation, and Maestro execution.

**Tech Stack:** Maestro CLI, YAML, SwiftUI, Xcodebuild, iOS Simulator (iPhone 17 / iOS 27.0+), Bash.

**Spec:** [`docs/superpowers/specs/2026-10-21-maestro-e2e-design.md`](file:///Users/skycherepanya/Developer/GitHub/calories-bot-mvp/docs/superpowers/specs/2026-10-21-maestro-e2e-design.md)

## Global Constraints
- App Bundle Identifier: `com.skycherepanya.Lifecore`
- Zero third-party runtime package dependencies in `Lifecore.xcodeproj`.
- Simulator environment: `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` with `iPhone 17`.
- English-only documentation, code comments, and commit messages; Ukrainian for chat communications.
