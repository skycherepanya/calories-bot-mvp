# Lifecore: AI Health Coach & Nutrition Data Warehouse
*Offline Analytics & Data Archive Module*

This subdirectory (`Lifecore/`) contains Python scripts for offline analysis of Apple Health and Strava data, reference system prompts for the AI Coach, and historical analytics reports.

**It forms a first-class submodule of the unified Lifecore repository.** The production Telegram bot and database architecture are documented in the [root README](../README.md).

## 🚀 Execution Guide (First-Time Setup)

### Step 1: Install Python Dependencies
```bash
pip install supabase pandas python-dotenv
```

### Step 2: Parse Apple Health XML → JSON Summary
```bash
cd Lifecore/
python scripts/deep_health_analysis.py
# → Generates reports/daily_health_summary.json
# Execution typically takes 2–5 minutes for a ~1.97 GB export file.
```

### Step 3: Ingest Historical Archive into Supabase
```bash
# After applying migrations 002 and 003 in Supabase:
python scripts/sync_to_supabase.py
# → Populates sleep_logs (HRV, RHR) and workouts (Apple Health + Strava)
```

### Step 4: Additional Analytics (Optional)
```bash
# Monthly trends (HRV, Resting HR, daily steps)
python scripts/analyze_health.py

# Step count distribution across sources (iPhone vs. Apple Watch)
python scripts/analyze_steps.py

# Running performance analysis (pace vs. distance vs. heart rate)
python scripts/analyze_strava.py
```

## 🔗 Connection to the Production Telegram Bot

Data generated and structured in this module feeds into the production Telegram bot via:
1. **`sync_to_supabase.py`** → One-time historical bulk ingestion of Apple Health and Strava logs into PostgreSQL.
2. **`shortcuts/ingest_health_shortcut.md`** → Automated daily synchronization via iOS Shortcuts directly to the `ingest-health` Edge Function.

Once stored in PostgreSQL, the `/coach` Telegram command performs multi-day recovery assessments using live physiological markers.
